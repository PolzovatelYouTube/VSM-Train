# Игровые ассеты VSM-Train

Все файлы созданы для проекта и лежат локально. Внешних URL нет. Лицензия — как у репозитория (MIT).

## Состав

| Файл | Что это | Происхождение |
| --- | --- | --- |
| `landscape/{day,sunset,night}-far.svg` | Дальний план за окнами: холмы, лес, огни посёлка ночью | Сгенерированы кодом: `python3 script/gen-landscapes.py`, seed фиксирован |
| `landscape/{day,sunset,night}-near.svg` | Ближний план: опоры контактной сети, провод, деревья | Тот же генератор |

Интерьер вагона и персонажи — векторные компоненты (`client/src/game/TrainInterior.tsx`, `CharacterSprite.tsx`), отдельных файлов у них нет.

Фотографии из материалов заказчика (интерьеры с реальными людьми) в игре **не используются**: по арт-гайду в кадре нет фотореалистичных лиц, реальных людей и логотипов третьих лиц.

## Арт-гайд первой итерации

- Ракурс: вид сбоку поперёк вагона на дальний борт; ближний ряд кресел — передний план.
- Пропорции: мир 400 условных единиц по высоте; пол дальнего борта — 300, окна — 78…205; взрослый персонаж — 250 единиц при масштабе 1 (глубина 0 → 0,78, глубина 1 → 1,08); ребёнок — ×0,66.
- Свет: ровный дневной; закат и ночь — тонирующий слой поверх салона (`LANDSCAPE_ASSETS[*].tint`).
- Палитра салона: светлые панели, бежевые/терракотовые кресла по классу, красная акцентная полоса. Проводник — тёмно-синяя форма, красный платок, фуражка.
- Контур: без обводок, плоские заливки, тени — затемнением цвета (без CSS-фильтров).
- Персонажи смотрят вправо (к голове поезда); влево — зеркально. Эмоции — брови и рот: `neutral`, `happy`, `worried`, `angry`.
- Кадр пейзажа: тайл 1600×400, левый и правый края совпадают, прокрутка — сдвиг ровно на ширину тайла.

## Бюджет

Игровой набор на сцену — 2 SVG (≈9–11 КБ) для выбранного пейзажа. Предзагружаются перед стартом смены (`preloadAssets`).

## Как добавить растровый ассет

1. Положить файл в эту папку (PNG/WebP с прозрачностью для персонажей, ≤ 200 КБ).
2. Добавить ключ в реестр `client/src/game/assets.ts` (например, `INTERIOR_PRESETS[key].image`).
3. Указать здесь происхождение и лицензию. Для сгенерированных изображений — сохранить промпт.
